# استقرار فرانت‌اند روی Vercel — راهنمای قدم‌به‌قدم (بدون نیاز به دانش فنی)

> مخاطب: صاحب پروژه | هدف: بالا آمدن سایت فروشگاه روی Vercel
> زمان: کمتر از ۵ دقیقه

## ⚠️ نکته قبل از شروع

این ریپو **مونورپو** است (چند پروژه در یک مخزن). تنها چیزی که Vercel باید بسازد،
فرانت‌اند در پوشه `apps/web` است. تمام تنظیمات دیگر (رابط با API، build خودکار
پکیج مشترک) داخل کد آماده است؛ **شما فقط باید مسیر پروژه را درست معرفی کنید.**

---

## روش پیشنهادی: حذف پروژه فعلی و ساخت دوباره (ساده‌ترین راه — ۳ کلیک)

اگر پروژه فعلی خطا می‌دهد، تمیزترین راه این است:

1. در Vercel وارد پروژه شوید → **Settings** → انتهای صفحه → **Delete Project**
   (نگران نباشید؛ فقط تنظیمات Vercel پاک می‌شود، کدهای GitHub سالم می‌مانند.)
2. از صفحه اصلی Vercel دکمه **Add New… → Project** → مخزن `karzintell` را انتخاب کنید → **Import**
3. در صفحه‌ای که باز می‌شود، Vercel خودش پوشه‌های پروژه را تشخیص می‌دهد؛
   کافی است **`apps/web`** را به‌عنوان Root Directory انتخاب کنید
   (معمولاً با عنوان «Next.js — apps/web» پیشنهاد می‌دهد — همان را بزنید).
4. دکمه **Deploy** → چند دقیقه بعد سایت بالا است. ✅

---

## روش دوم: اصلاح پروژه فعلی (بدون حذف)

اگر نمی‌خواهید پروژه را حذف کنید:

1. **Settings → General → Root Directory** → Edit → پوشه **`apps/web`** را انتخاب کنید → Save
2. **Settings → General → Build & Development Settings:**
   - Framework Preset: **Next.js**
   - Build Command / Output Directory / Install Command: **همه را خالی بگذارید** (Override خاموش)
3. **Deployments → آخرین مورد → Redeploy**

---

## متغیر محیطی API (فعلاً لازم نیست!)

سایت بدون هیچ متغیری Deploy می‌شود. چون هنوز بک‌اند روی اینترنت مستقر نشده،
فعلاً چیزی برای وارد کردن نیست. هر وقت بک‌اند را روی سرور بالا آوردید:

| نام | مقدار نمونه |
|---|---|
| `NEXT_PUBLIC_API_URL` | `https://api.damaneh.ir/api/v1` |

از مسیر: **Settings → Environment Variables** → Add → ذخیره → Redeploy

---

## بک‌اند کجا مستقر شود؟

بک‌اند (NestJS) + MySQL/MariaDB + Redis روی Vercel اجرا **نمی‌شود**. گزینه‌ها:

| گزینه | مناسب برای | روش |
|---|---|---|
| VPS (ایران/خارج) | بهترین و استانداردترین | راهنمای `DEPLOY-MYSQL.md` + `docker compose up -d` |
| لیارا / ابرآروان / هم‌روش | بدون دردسر سرور | سرویس Node.js + دیتابیس MySQL/MariaDB مدیریت‌شده |

پس از بالا آمدن API، همان متغیر `NEXT_PUBLIC_API_URL` بالا را تنظیم کنید و سایت کامل وصل می‌شود.

## رفع خطاهای رایج

| خطا | علت | راه‌حل |
|---|---|---|
| `No Output Directory named "public"` | Root Directory روی ریشه ریپو است | روش دوم، قدم ۱ |
| `Module '@karzintell/shared' not found` | نصب در پوشه apps/web به‌تنهایی | مطمئن شوید `vercel.json` فقط `framework` دارد و Install Command خالی است |
| `TS2305 ... utils` | دیپلوی از کامیت قدیمی | Redeploy روی آخرین کامیت |
| صفحه باز می‌شود ولی «خطا در اتصال به سرور» | API هنوز مستقر نشده | طبیعی است؛ بعد از استقرار بک‌اند رفع می‌شود |
