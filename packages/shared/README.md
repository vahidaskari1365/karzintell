# @karzintell/shared — تایپ‌ها و ثابت‌های مشترک

منبع واحد حقیقت بین فرانت و بک‌اند:

- `permissions.ts` — کلیدهای مجوز RBAC (هم‌خوان با seed دیتابیس)
- `roles.ts` — نقش‌های سیستمی
- `types.ts` — Envelope پاسخ API، وضعیت‌های دامنه (سفارش/محصول/دیدگاه/کاربر)

در مرحله ۲ به‌صورت پکیج workspace به‌کار می‌رود: `packages/shared/package.json` + `tsconfig`.
